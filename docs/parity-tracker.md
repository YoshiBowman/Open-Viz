# Parity Tracker

Status of every parity requirement. Detail and sources are in `2026-10-07-requirements-and-roadmap.md`.

- **Has**: D = Depence, C = Capture
- **Phase**: roadmap phase where it lands
- **Status**: `todo` / `stock` (Unreal already does it, needs wiring or tuning) / `wip` / `done`. A parser row only becomes `done` once real manufacturer files pass, not just the hand-written test fixtures.
